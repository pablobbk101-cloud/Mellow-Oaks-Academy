# Mellow Oaks Academy: website concept

Concept website for Mellow Oaks Academy (Roodepoort), designed by Pablo Lebelo (mrpoint.online). Not the official school website. Every page is marked `noindex` and carries a concept banner.

Static pages generated by `tools/build.py` (content, pages and photos in one place). `styles.css` and `fx.css` (design system, see `DESIGN.md`), `site.js` (menus), `fx.js` (GSAP motion, libraries in `vendor/`) and `apply.js` (five-step application demo) are edited directly. The enquiry and application forms are demos: nothing is stored or sent.

Deploy: Cloudflare Workers & Pages, import this repository, no build command.
